Quick Start:

  1. Download the launcher from https://brickforce-aurora.de/download/
  2. Run the launcher and install the game. Note: if you can't start via the button, go to your install folder and start BrickForce.exe directly
  3. After starting the game, add your name into the email field and use the host menu (F6) to host or join a game. More details:
    • Steam: How can I play together with others? (Steam)
    • IP: How can I play together with others? (IP)
    • ModMenu Help: I can't open the Mod (Steam) Menu (F6) / Game crashes when I interact with that Menu

We are currently two developers working on the main game and one developer working on the launcher. Due to our limited free time, we cannot give any estimate on the time until a specific bug fix or feature is being implemented.

The gamecode is open source, so anybody can contribute and open a merge request. More information: How can I start with development?

Cheers, the BF-Aurora Dev-Team

How can I play together with others? (Steam) 

Start Steam and install Spacewar (App ID 480). Link: steam://install/480/
Start the game and host a lobby via Steam or join a running Steam lobby. Someone still needs to host the game.

How can I play together with others? (IP) 

Get into a network with other players (VPN or LAN). Recommended service: Radmin VPN. Make sure to allow any firewall exceptions that may pop up in the process. One player will act as host, make sure to put his network IP in the Host IP text field after starting the game (default value can be set in Config). You can use localhost as Host IP (127.0.0.1) if you just want to test alone. Put your custom username into the regular E-mail text field. Host needs to click Host Match, after that the other players click Join Match. After connecting, click Play to proceed to the main menu and create a room (others may need to refresh the room list in order to join). Make sure everyone has the files for the current map loaded. Room master can start the match once every player is ready (you can also start alone).

I am stuck in "Downloading Once..." 

Most likely, something is faulty in your config. To fix this issue, go to the Registry Editor and navigate to: Computer\HKEY_CURRENT_USER\SOFTWARE\EXE Games\BrickForce, and delete the EXE Games folder. Restart the game, and it should work.

How can I start with development? 

Install Visual Studio 2022 and .NET Desktop Development. Using "Install or Change Feature," install .NET Framework 3.5. Open the solution file Brick-Force.sln. Install the Launcher and the Game into the same folder where the Brick-Force Repository Folder is to resolve all dependencies (e.g., Folder/BfLauncher and Folder/Brick-Force). Change the Build Output Path to Brick-Force_Data/Managed in project properties. If necessary, reimport ICSharpCode.SharpZipLib.dll as a reference. To debug, select Brick-Force.exe as the external program.
