 Upgrade Gems

One of the features Brick-Force is offering is the Upgrade. All items are upgradable, except for some event gear and Pick ‘N’ Win prizes. In order to upgrade an item, you will first need to get some Upgrade Gems.

Enter the shop section “Upgrades” to buy one. There are two different groups of gems: one set of colors for weapons and one for clothing and accessories.

You will need different Upgrade Gems, depending on what it is you want to upgrade – outfits or weapons.

Select an item that you want to upgrade by clicking on it in your inventory and click the little blue “Item Upgrade” button on the bottom to enter the upgrade interface. For our example, we have chosen the Bronto 1000.

Select an item from your inventory that you want to upgrade and click the blue “Item Upgrade” button.

The non-Elite weapon or equipment Gems (green, blue and pink) can be used to upgrade one random weapon or equipment property, respectively. The Small Gem (green) can be used by any rank player and will work until all properties are upgraded to level 3. If you want to upgrade properties to a higher level than 3, you will need a Medium Gem (blue) which works for players from rank “Warrant Officer 3” and higher and up to property level 6. From property level 7 onwards, you will need a Big Gem (pink) and at least rank “Captain 5”.

Upgrading an item which has not yet been enhanced will never fail. However, if you upgrade an already enhanced item, there might be a chance of failure. Non-Elite Gems can be bought for both Tokens and Force Points.

Green, blue or pink Upgrade Gems are bound to a certain player rank in order to work. Select a Gem package and press “Item Upgrade” to start the upgrade.

With Elite Gems, you get the ultimate upgrade. They will never fail, aren’t bound to any rank and you can select yourself which property you want to upgrade. As you can see in our example, we have chosen the Damage stat to be enhanced. Pressing “Item Upgrade” will increase this to level 1. Elite Gems can only be bought with Tokens.

Elite Gems give you the ultimate upgrade. They will never fail, aren’t bound to any rank and you can select yourself which property you want to upgrade.
