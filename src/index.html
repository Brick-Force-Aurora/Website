  • Brick-Force Aurora

    March 24, 2026

    Greetings Community,

    We're excited to announce the next version of 2.3.0. It is a big update for building and for the server underneath the game. It adds the following features:

    • 🧱 BrickEdit, a new build tool for Build Mode (bound to key T). Commands: //pos1, //pos2, //sel, //remove, //set, //set hollow, //replace, //replace near and //remove near
    • 📊 Performance Overlay (F9): FPS counter, memory consumption / GC stats and a frame timing history graph. FPS limiting and VSync can be set in the F6 menu (Config)
    • 🛒 New shop items: 'Reset Map Slot' and 'Premium Account'
    • 🧱 Added a brick build limit of 1000 to the red_brick_2 barrier brick and removed the build limit for most other bricks
    • 🔧 Debugging support, described in the README on GitHub

     

    Maps

    • 🗺️ "Result Team Match" and "Lobby" are now playable
    • 🗺️ Update to Jezzey's map "Aurora", a new version of Warehouse, the correct version of Aftermath (the second version was removed) and a fixed Skylands

     

    Build Mode

    • 🔨 Generated Build Mode maps are now created in the center of the map, 30 below the minimum build height, so you can also build below the generated plane
    • 🔨 You now spawn in the center of the map, slightly above its highest point
    • 🔨 Reworked map slots: to edit a map you now have to load it into the map slot first, using the Map Manager (My Downloaded Maps) and the button "add to slot". To reset a map slot you need the Reset Map Slot item in your inventory (only available in F5)
    • 🛠️ Fixed the Line tool and the Swappie tool, the bounding box and loaded state of generated maps, non-host players creating and saving their own Build Mode rooms and newly created maps not being saveable

     

    Changes

    • ⚙️ Character levels are set to level 65
    • ⚙️ The map size limit is back to 100 * 100 * 100 bricks, which fixed performance issues
    • 🌐 The server runs separately from the game for the host, in its own thread, and handles packets better, which means better performance and quicker loading times
    • 🌐 The server no longer sends all maps to the player, the player loads their local maps instead. Map registration is now done fully clientside
    • 🌐 Improved the server disconnecting clients and Steam networking (each network channel has its own queue now)
    • 🗺️ The 'Downloaded Maps' list is no longer paged but a list with a filter
    • ⚙️ The 'Drop' option in the room options is disabled (it caused weapons to randomly go away and is forced off by the server until it is implemented)
    • ⌨️ Going up and down in the command history puts the cursor at the end of the command

     

    Bug fixes

    • 🛠️ Fixed hosting over IP dropping packets that were too big or sent too quickly
    • 🛠️ Fixed players not being able to reconnect after timing out or getting kicked out of a Steam lobby, and clients/servers not timing out correctly
    • 🛠️ Fixed typing in chat not blocking palette interactions and the palette starting empty in Build and Destroy and Build Mode
    • 🛠️ Fixed room map changes not being recognised by the client and some game modes not ending the match correctly
    • 🛠️ Build and Destroy: fixed maps not transferring when joining an in-progress match, special item limits not being per map, existing blocks not being destroyable, joining in the wrong phase and building in the Destroy phase

     

    Please note that BrickEdit might leave visual artifacts, especially when removing blocks. If this happens, simply save and rejoin the map. If you are not the room owner, simply rejoining works.

    Please note that the debugging support does not fully work in later Visual Studio, Unity and dnSpy versions. For the best results use Visual Studio 2017.

    The full changelog is on GitHub.

  • Brick-Force Aurora

    January 19, 2025

    Greetings Community,

    We're excited to announce the next version of 2.0.0. The update is available in the Launcher and adds the following features:

    • 🛒 Fixes for Shop and Inventory
    • Implemented Steam API for matchmaking, networking and friends (Spacewar)
    • Added new, more advanced menu based on Dear ImGui (F6)
    • Added new config options

     

    This marks a big change in how this mod works, as you can now play via Steam with all the features that come with it.

    Steam enables us to have a centralized lobby system where you can create and join lobbies with a lobby list. You can also invite Steam friends or join their lobby directly.

    The new networking also happens through Steam and you won't have to use the old method via raw IP anymore (it's still there if you need it).

    As always, you can grab the update from the launcher, but to enable Steam play, some additional steps are required:

    • Install and run Steam, create or login to your Steam account
    • Install 'Spacewar' (Proxy for Steamworks API access) to your Steam Library by opening steam://install/480/ in your browser while Steam is running
    • Run Brick-Force through BfLauncher.exe or BrickForce.exe while Steam is running
    • Steam should show you as playing 'Spacewar'
